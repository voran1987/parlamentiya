# Парламентия: табло

Табло для игры «Парламентия» (тема 5, лекция 1 «Политические партии и партийные системы»).
Ведущий управляет игрой, студенты на смартфонах видят рейтинги, ресурсы, события и парламент в реальном времени.

Адрес табло: https://voran1987.github.io/parlamentiya/

## Как это устроено

- `index.html` — вся игра в одном файле.
- `firebase-config.js` — подключение к базе Firebase Realtime Database (общее состояние игры).
- `database.rules.json` — правила доступа: читать табло может любой, писать только тот, кто знает ключ ведущего.

Пока в `firebase-config.js` стоит `null`, табло работает в локальном режиме на одном устройстве, без синхронизации.

## Настройка за 10 минут

1. Откройте https://console.firebase.google.com и создайте проект (Google Analytics не нужен).
2. В проекте: Build → Realtime Database → Create database. Выберите регион (например, europe-west1), режим «Locked mode».
3. Вкладка Rules: вставьте содержимое `database.rules.json` и нажмите Publish.
4. Вкладка Data: нажмите «+» у корня и добавьте узел `secret` со значением вашего ключа ведущего (любая длинная строка из букв и цифр, например `Parl-7Kq2xW9mT4`). Узел `secret` клиенты прочитать не могут.
5. Project settings → Your apps → значок `</>` (Web) → зарегистрируйте приложение и скопируйте объект `firebaseConfig`.
6. Вставьте его в `firebase-config.js` вместо `null` и сохраните файл в репозитории.
7. GitHub Pages: Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.

## Как пользоваться

- Ведущий открывает один раз: `https://voran1987.github.io/parlamentiya/?key=ВАШ_КЛЮЧ`. Ключ запоминается в браузере, из адреса он убирается. Вверху надпись «Ведущий».
- Студенты открывают `https://voran1987.github.io/parlamentiya/` (или сканируют QR-код: кнопка «QR для студентов»). Вверху надпись «Просмотр», кнопок управления нет.
- Если вверху написано «Не сохранено: проверьте ключ ведущего», ключ в ссылке не совпадает со значением `secret` в базе.
- Начать игру заново: кнопка «Сбросить игру» (нажать дважды).
