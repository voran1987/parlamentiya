# Своя игра — Конституция Российской Федерации

Игра в оформлении загруженного HTML-образца «Своя игра — Основы государственности» (светлый фон, цветные категории, крупные ячейки и табло команд под полем). Два тура по 25 **открытых вопросов** и суперигра.

## Ссылки

- Запуск игры: https://voran1987.github.io/parlamentiya/constitution-game/
- Репозиторий: https://github.com/voran1987/parlamentiya/tree/main/constitution-game
- Backend: Supabase Edge Function `constitution-game-api`, проект `logzbhhftwvqsrqvmnik`
- Источник для вопросов: https://www.minjust.gov.ru/ru/documents/8011/

## Сценарий

1. Ведущий создаёт комнату и выводит на экран постоянный QR-код (закреплён внизу страницы).
2. Студенты подключаются без пароля, вводят имя и выбирают одну из **пяти команд**. Названия команд редактирует ведущий.
3. **Тур I:** 5 тем × 5 ячеек стоимостью 100, 200, 300, 400, 500. Ведущий выбирает ячейку, вопрос раскрывается всей аудитории.
4. Команды обсуждают и **вводят один ответ текстом** (без вариантов A, B, C, D). На каждый вопрос база принимает только один ответ от команды; повторные попытки блокируются.
5. Ведущий читает ответы команд и отмечает «Верно», «Неверно» или «0 баллов». Правильный ответ для преподавателя скрыт в сворачиваемом блоке и не показывается аудитории до нажатия «Показать ответ всем».
6. При «Верно» начисляется стоимость вопроса, при «Неверно» снимается половина стоимости; при «0 баллов» или отсутствии ответа счёт не меняется. Начисление производится атомарно на сервере.
7. **Тур II:** 5 тем × 5 ячеек стоимостью 200, 400, 600, 800, 1000, такая же механика. Все 50 вопросов отличаются по формулировкам.
8. **Суперигра:** ведущий выбирает одну из трёх финальных тем, команды вводят текст и ставку кратную 100. Правильный ответ добавляет ставку, неправильный снимает её.
9. В конце игры показывается рейтинг команд и доступна выгрузка CSV.

### Сколько времени нужно

Вопросы выбираются в свободном порядке, поэтому необязательно проходить все 50 ячеек за одно 90-минутное занятие. Если играть все, время следует увеличить либо ограничить обсуждение каждого вопроса.

### Управление с другого компьютера

Ведущий копирует кнопку **«Секретная ссылка ведущего»**. Только эта ссылка позволяет управлять игрой; её нельзя раздавать студентам. QR ведёт на отдельную ссылку для участников.

### Начать заново

«Сбросить игру» удаляет ответы, сыгранные вопросы и баллы, но сохраняет участников. Новая комната отделяет новую группу студентов.

### Архитектура

- `index.html` — интерфейс браузера в стиле исходного образца.
- `api/index.ts` — точная копия Supabase Edge Function. Ключ service_role не попадает на клиент.
- Таблицы: `constitution_sessions`, `constitution_teams`, `constitution_players`, `constitution_answers`.
- В таблице ответов действует уникальность `(room_code, question_key, team_num)`.
- `constitution_apply_grade` — PostgreSQL-функция атомарной фиксации оценки и счёта, право вызова предоставлено только `service_role`.
- Все таблицы защищены RLS и не открыты для прямого доступа браузера.
- `smoke_test.py` запускается автоматически GitHub Actions и проверяет создание комнаты, 25+25 вопросов, текстовые ответы, запрет дублей, оценивание, суперигру и сброс.

> Старые сессии тестовой версии игры с вариантами ответа следует заменить новой комнатой: сохранённые в них ответы предыдущего формата не переводятся автоматически в текстовые ответы.
