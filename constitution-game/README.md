# Своя игра: Конституция Российской Федерации

Оригинальная учебная командная игра для семинара в НИУ «МЭИ»: **два тура и суперигра**. Работает в браузере, студенты заходят со смартфонов через QR-код без пароля; ведущий управляет вопросами со своего экрана.

## Открыть

- Игра: https://voran1987.github.io/parlamentiya/constitution-game/
- Сервер: Supabase Edge Function `constitution-game-api` в проекте `logzbhhftwvqsrqvmnik`.
- Исходный код функции: `api/index.ts` (копия опубликованной версии).
- Текст Конституции: https://www.minjust.gov.ru/ru/documents/8011/

## Порядок проведения

1. Ведущий нажимает «Создать игровую комнату». Приложение создаёт случайный шестизначный код и секретный ключ ведущего.
2. QR-код **постоянно закреплён внизу экрана ведущего** и ведёт на ссылку регистрации студентов, не на ссылку управления.
3. Студент вводит имя, выбирает одну из пяти команд. Ведущий может переименовать команды. Можно участвовать нескольким студентам от одной команды.
4. Нажмите «Начать первый тур». В каждом туре 4 категории по 3 вопроса (12 ячеек). Ведущий выбирает любую ещё не сыгранную ячейку.
5. После открытия вопроса у студентов есть 45 секунд, чтобы обсудить ответ. **Первый полученный ответ команды принимается, все остальные попытки блокируются сервером**; каждый студент видит факт сдачи после обновления.
6. Ведущий нажимает «Показать правильный ответ», после чего начисляются очки: правильный ответ **+стоимость вопроса**, неправильный **−половина стоимости**, отсутствие ответа — **0**.
7. После закрытия вопроса выбирается следующий. По окончании I тура ведущий переходит во II тур; несыгранные вопросы предыдущего тура будут пропущены.
8. **Суперигра:** ведущий выбирает одну из трёх финальных тем. Каждая команда одновременно выбирает ставку кратную 100 (от 0 до своего текущего счёта; командам с небольшим или отрицательным счётом разрешена ставка до 300), затем отправляет один ответ. Верный ответ прибавляет ставку, неверный — вычитает. После раскрытия правильного ответа ведущий завершает игру.
9. Итоговая таблица показывает общий командный рейтинг; есть экспорт CSV.

## Управление на другом компьютере

Ведущий копирует **«Секретную ссылку ведущего»** в комнате и открывает её на другом устройстве. Ссылку нельзя распространять среди студентов — она предоставляет полномочия управления игрой. Вход студентов осуществляется **только через QR или обычную ссылку команды**.

## Начать игру заново

Кнопка «Сброс игры» сбрасывает ответы, сыгранные вопросы и очки в текущей комнате, но сохраняет подключения студентов. Для полностью новой группы создайте новую комнату на главном экране.

## Техническая реализация

- Статика GitHub Pages: `index.html`.
- API: Supabase Edge Function, без ключа service_role в браузере.
- Таблицы: `constitution_sessions`, `constitution_teams`, `constitution_players`, `constitution_answers`.
- В таблице ответов первичный ключ `(room_code, question_key, team_num)`, исключающий два ответа от одной команды на один вопрос.
- RLS включён для всех четырёх таблиц; доступ из браузера только через серверную функцию.
- Секрет ведущего генерируется случайным UUID, студенческий токен привязывается к записи участника.
- QR-код в интерфейсе формируется внешним сервисом, с резервным сервисом на случай недоступности первого.
- Вопросы и правильные ответы содержатся только в серверном коде до момента раскрытия.

> Ссылка на пример Claude Artifacts, предоставленная пользователем, не открылась средствами автоматизированного просмотра. Поэтому это самостоятельная реализация жанра «Своя игра», а не дословное воспроизведение исходного артефакта.

## Педагогическая схема

Разминка и объяснение правил (5 мин), I тур (25 мин), II тур (35 мин), суперигра и итоги (15–20 мин). По усмотрению преподавателя можно проводить часть ячеек, не отыгрывая все 24 вопроса.
