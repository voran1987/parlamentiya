# Своя игра: Конституция РФ

Учебная «Своя игра» по Конституции Российской Федерации для семинаров МЭИ. Оформление соответствует загруженному образцу (светлый фон, пять цветных колонок, табло команд под полем).

**Сайт:** https://voran1987.github.io/parlamentiya/constitution-game/

## Состав

- **Тур I:** 25 вопросов, 5 тем × 5 уровней сложности (100–500 очков).
- **Тур II:** 25 вопросов, 5 тем × 5 уровней сложности (200–1000 очков).
- **Тур III:** один общий сложный конституционный кейс. Каждая команда независимо выбирает ставку и отправляет письменный ответ.
- 5 команд, QR для входа студентов всегда виден внизу экрана ведущего.
- В первых двух турах ответы **вслух**, на скорость. В третьем туре — **письменные ответы и ставки каждой команды**.
- Один шанс нажатия для команды в турах I–II; один письменный ответ на всю команду в туре III.

## Как проходит вопрос

1. Ведущий открывает ячейку. На смартфонах появляется крупная кнопка **«ОТВЕТИТЬ»**.
2. Сервер Supabase атомарно фиксирует **первый полученный** сигнал. На экранах показывается название команды, получившей право устного ответа. Пока ведущий слушает ответ, остальные кнопки заблокированы.
3. Ведущий нажимает **«Верно»**, **«Неверно»** или **«0 баллов»**. При верном ответе вопрос завершается; ведущий раскрывает правильный ответ и закрывает ячейку.
4. При неверном ответе у команды списывается половина стоимости вопроса; **кнопки остальных команд снова разблокируются**, но первая команда повторно нажать уже не сможет.
5. При верном ответе команда получает стоимость вопроса. Если никто не знает ответа, ведущий открывает правильный ответ без начисления баллов.
6. **Тур III:** ведущий открывает единый сложный вопрос. Команды выбирают ставку кратную 100, не выше своего счёта (или до 300 для команды с малым/отрицательным счётом), и независимо вводят текст.
7. Кнопка «Завершить приём ответов» останавливает отправку всем командам. Пока приём открыт, ответы соперников скрыты; после его закрытия ведущий видит все тексты и ставки.
8. Ведущий оценивает каждый ответ: **верно +ставка**, **неверно −ставка**, **частично — 0 баллов**. Пропуск ответа не меняет счёт. Правильный ответ открывается всем только после проверки; затем подводятся итоги.

**Важно:** объективный порядок определяет **момент поступления запроса на сервер**. Между смартфонами возможны сетевые задержки; игра не гарантирует идеальную справедливость на уровне миллисекунд.

## Вход преподавателя и студентов

Ведущий открывает игру и создаёт комнату. У ведущего есть секретная ссылка, позволяющая открыть управление с другого компьютера. Студентам следует выдавать только QR или обычную ссылку, без секретного ключа ведущего.

## Запуск и сброс

Кнопка «Сбросить игру» обнуляет использованные вопросы и баллы при сохранении подключённых студентов. Для новой группы создайте новую комнату.

После изменения формата третьего тура рекомендуется создать новую игровую комнату, чтобы избежать несовместимости со старыми финальными вопросами.

## Архитектура и безопасность

- GitHub Pages: `index.html`.
- Supabase Edge Function: `constitution-game-api`, исходник в `api/index.ts`.
- PostgreSQL: `constitution_sessions`, `constitution_teams`, `constitution_players`, `constitution_answers`; у всех таблиц включён RLS.
- Ролевые ключи Supabase не передаются браузеру; серверные действия защищены токеном участника или секретом ведущего.
- PostgreSQL `constitution_claim_buzz` сериализует претендующие команды на блокировке игровой комнаты, выбирая один сигнал и блокируя остальные.
- PostgreSQL `constitution_apply_grade` атомарно обновляет оценку, счёт и доступность кнопки для других команд в турах I–II.
- PostgreSQL `constitution_submit_final` принимает один письменный ответ со ставкой от команды; `constitution_apply_final_grade` атомарно начисляет или списывает её.
- `smoke_test.py` проверяет нажатия на скорость в турах I–II, а также независимые письменные ответы, приватность, ставки, блокировку повторной отправки, оценивание и завершение третьего тура.

Содержание вопросов составлено на основе актуального текста Конституции РФ: https://www.minjust.gov.ru/ru/documents/8011/
