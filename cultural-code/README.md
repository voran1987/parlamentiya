# Расшифруй культурный код

Интерактивная игра для практического занятия № 2 по дисциплине «Основы российской государственности».

## Прямой адрес
https://voran1987.github.io/parlamentiya/cultural-code/

## Источники
А. Д. Харичев, А. В. Полосин, А. В. Селезнёва. «Основы российской государственности». РАНХиГС, 2024, раздел III, гл. 1, с. 238–254.
План-конспект: занятие 2, «Формы репрезентации мировоззрения». РПД НИУ «МЭИ», тема 1.3.

## Проведение (90 минут)
- 15 минут — обсуждение домашнего задания «Мои герои».
- 30 минут — мини-лекция: герои и социализация, пять форм репрезентации.
- 40 минут — игра: 15 вопросов, три тематических раунда, обсуждение ответов.
- 5 минут — подведение итогов.

## Вход ведущего
Откройте прямой адрес, выберите 60–120 секунд и нажмите «Создать игру». Запишите шестизначный код или покажите QR на проекторе. Ведущий начинает игру, закрывает ответы и показывает разбор. Доступ ведущего сохраняется на текущем устройстве. Для другого компьютера используйте кнопку «Ссылка ведущему на другой компьютер» (не отправляйте её студентам).

## Вход студентов
Откройте QR-ссылку или адрес игры, введите код, имя и выберите команду. Отвечайте со смартфона. После разбора каждый увидит правильный вариант, объяснение и общий рейтинг.

## Педагогика
Темы: «идеи и язык», «нормы», «институты», «ритуалы», «символы». Вопросы построены по схеме «форма — ценность — идентичность». Все формулировки оригинальные, с привязкой к страницам учебника. Оценивание: +100 за правильный ответ; командный рейтинг по среднему баллу на участника. Игра помогает освоить УК-5/ИД-2УК-5.

## Техническая архитектура
GitHub Pages: `cultural-code/index.html`. Supabase Edge Function: `cultural-code-api`. База данных: `cc_sessions`, `cc_players`, `cc_answers`. Доступ к таблицам со стороны анонимных клиентов закрыт; действия выполняются через API с токенами комнаты и участника. Без интернета многоустройственный режим не работает.

## Важно
QR-код генерируется внешним сервисом qrserver.com (в QR передаётся только публичная ссылка на присоединение). Доступ ведущего держите в секрете. Псевдонимы предпочтительнее персональных данных.

## Сценарий 90-минутного занятия (версия 2)

| Этап | Продолжительность |
| --- | ---: |
| Введение, объяснение пяти форм и правил | 5 мин |
| Раунд 1: пять заданий на классификацию | 10 мин |
| Раунд 2: «Исследовательская лаборатория» — пять самостоятельных заданий | 45 мин |
| Защита командных решений и экспертные комментарии | 15 мин |
| Раунд 3: пять ситуационных кейсов | 10 мин |
| Итоговое обсуждение, рейтинг и рефлексия | 5 мин |

Каждая из пяти команд («Идеи и язык», «Нормы», «Институты», «Ритуалы», «Символы») получает собственную подсказку. В исследовательском раунде пять последовательных заданий: два примера, ценности, идентичность, критическое рассмотрение, конструирование собственного проекта. Каждый ответ вводится в четыре текстовых поля и сохраняется на сервере. Ведущий может оценить каждую командную работу от 0 до 5 баллов и оставить комментарий. Личные тестовые ответы приносят по 100 баллов, оценки работ добавляют участникам соответствующей команды по 100 баллов за экспертный балл.

Для полноценного проведения ведущий переключает шаги после обсуждения; у письменной части нет жёсткого таймера. QR-подключение и код комнаты остаются прежними. Проверьте новый сценарий на двух устройствах перед занятием.
