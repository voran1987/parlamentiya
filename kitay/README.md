# КНР: баланс сил — интерактивная игра

Семинарская политологическая симуляция по теме «КНР в мировой политике» на основе механики «Революционной ситуации».

## Адрес игры

https://voran1987.github.io/parlamentiya/kitay/

## Проведение

Ведущий создаёт игровую комнату и выбирает 4–6 делегаций. Студенты подключаются по коду или QR, обсуждают ситуацию и принимают тайные решения на телефонах. После выступлений ведущий раскрывает выборы, а игра пересчитывает пять глобальных показателей и очки команд.

Шесть кризисных раундов, три варианта итогового исхода и экспорт результатов в CSV. Сценарии 2027 года вымышлены; это учебная модель, а не прогноз.

## Подключение Firebase Realtime Database

Приложение уже использует общий `../firebase-config.js` и пишет только в ветку `china_world_politics/<КОД>`.

**Один обязательный ручной шаг:** в Firebase Console откройте проект `parlamet-536a2` → Realtime Database → Rules, сравните правила в консоли с актуальным `database.rules.json` репозитория и добавьте новый узел `china_world_politics`. Сначала сохраните резервную копию действующих правил; не заменяйте их целиком, если они отличаются от GitHub. Затем нажмите **Publish**. GitHub-коммит не публикует правила в Firebase.

Новый узел:

```json
"china_world_politics": {
  ".read": false,
  "$code": {
    ".validate": "$code.matches(/^[A-Z0-9]{4}$/)",
    ".read": true,
    ".write": true
  }
}
```

**Проверка:** ведущий создаёт комнату; на другом устройстве участник входит по четырёхсимвольному коду, выбирает делегацию и отправляет решение. В окне ведущего должна обновиться отметка «решение принято», затем следует проверить раскрытие, подсчёт очков и переход к следующему раунду.

**Ограничение безопасности:** как и в `revolyuciya`, этот вариант правил допускает запись без авторизации внутри комнаты для всех, кто знает её код. Он подходит для доверенной учебной аудитории, но не защищает роль ведущего от намеренного вмешательства в базу. Для публичных соревнований нужна отдельная система авторизации и более строгие правила.

## Firebase

Приложение загружает общую конфигурацию из `../firebase-config.js`, аналогично игре `revolyuciya`. Комнаты новой игры используют отдельную ветку Realtime Database: `china_world_politics/КОД`.

**Внимание:** для реального подключения студентов с разных устройств правила Firebase должны разрешать необходимые действия для нового пути. Публикация кода GitHub не меняет правила Firebase и не гарантирует доступ к базе. Если Firebase недоступен, приложение автоматически предлагает локальный демонстрационный режим, который работает только в рамках браузера на одном компьютере.

**Приватность:** скрытие вариантов решения до раскрытия обеспечивается интерфейсом игры, а не защищёнными ролями Firebase. Не используйте игру для хранения конфиденциальной информации или персональных данных студентов без отдельных механизмов контроля доступа.

## Организация проекта

- `kitay/index.html` — самодостаточное игровое приложение.
- `firebase-config.js` — общий файл конфигурации в корне репозитория.
- `revolyuciya/` — другая игра, её файлы не изменяются.

## Если GitHub Pages показывает 404

Проверьте GitHub → Settings → Pages: Source «Deploy from a branch», Branch `main`, Folder `/ (root)`. В разделе Actions проверьте успешное завершение `pages build and deployment`. Адрес игры: https://voran1987.github.io/parlamentiya/kitay/index.html. После публикации обновите страницу без кэша (Ctrl+F5). Эта запись также инициирует новый коммит публикации.
