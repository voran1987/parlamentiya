# КНР: баланс сил — дипломатическая интерактивная игра

Семинарский политологический симулятор по теме «КНР в мировой политике», шесть кризисных раундов, шесть делегаций, пять индикаторов и три возможных исхода.

## Запуск

**Сайт:** https://voran1987.github.io/parlamentiya/kitay/

**Бэкенд (с 1 ноября 2026): Supabase**, проект `politology-games` (регион Париж, `eu-west-3`). **Firebase для этой игры больше не используется**; файл `firebase-config.js` в корне репозитория оставлен для других игр.

**Как играть:** ведущий создаёт комнату, выбирает 4–6 делегаций и выводит QR-код на проектор. Студенты входят по коду, выбирают делегацию, ведут переговоры и принимают тайные решения. Ведущий управляет этапами, раскрывает решения и может экспортировать результаты в CSV.

## Как работает Supabase

- `kitay/index.html` — единый HTML/CSS/JS интерфейс, напрямую обращается к Supabase Edge Function по HTTPS.
- `kitay/supabase/china-game/index.ts` — исходный код активной Edge Function `china-game`.
- `kitay/supabase/schema.sql` — описание таблицы `china_game_rooms` и её ограничений доступа.
- Проект Supabase: https://supabase.com/dashboard/project/logzbhhftwvqsrqvmnik
- Серверный API: `https://logzbhhftwvqsrqvmnik.supabase.co/functions/v1/china-game`.

Состояние комнаты обновляется на клиентах опросом примерно каждые **1,8 секунды**. Ведущий получает криптографически случайный локальный ключ комнаты; делегации закрепляются за устройством отдельными секретными ключами. В базе хранятся только SHA-256 хеши этих ключей. Прямой доступ браузеров к таблице запрещён; Edge Function обращается к ней с серверными учётными данными Supabase. **Никогда не добавляйте service-role key в HTML или GitHub.**

В текущей модели посетитель с кодом комнаты может просматривать общедоступные сведения и готовность команд, но не может изменять комнату без ключа ведущего или закреплённой делегации. До раскрытия результаты чужих тайных решений скрываются сервером. Ключ ведущего хранится только в браузере, создавшем комнату: не удаляйте данные этого браузера до конца занятия. Комнаты имеют срок действия **30 дней**; история старых комнат Firebase автоматически не перенесена.

Если нужно обновить серверную функцию, отправляйте исходник `kitay/supabase/china-game/index.ts` в проект Supabase как функцию с именем `china-game` и параметром `verify_jwt=false`: функция выполняет собственную проверку случайных секретов игроков/ведущего.

## Проверка после публикации

1. Откройте сайт по ссылке выше и создайте **новую** комнату.
2. На другом телефоне войдите по QR-коду и выберите делегацию.
3. Запустите игру, перейдите к тайному выбору и отправьте решение с телефона.
4. На экране ведущего должна обновиться готовность делегации; после раскрытия должны появиться её решение и результат раунда.
5. Проверьте переход к следующему раунду и экспорт CSV.

Если отображается прежняя версия, откройте сайт в приватном окне или обновите страницу Ctrl+F5. Если запросы Supabase не проходят, интерфейс покажет ошибку подключения; проверьте состояние Edge Function `china-game` в панели проекта.

## Иллюстрации

Карта построена по географическим контурам **Natural Earth 1:110m**, встроенным в HTML, поэтому сама карта не зависит от картографических серверов. Фотографии раундов — документальные материалы Wikimedia Commons, подписанные источниками и лицензиями; в условной истории 2027 года они служат лишь иллюстрациями. Снимки загружаются с Wikimedia Commons при наличии доступа в интернет.
