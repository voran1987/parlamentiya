# КНР: баланс сил — интерактивная игра

Семинарская политологическая симуляция по теме «КНР в мировой политике» на основе механики «Революционной ситуации».

## Адрес игры

https://voran1987.github.io/parlamentiya/kitay/

## Проведение

Ведущий создаёт игровую комнату и выбирает 4–6 делегаций. Студенты подключаются по коду или QR, обсуждают ситуацию и принимают тайные решения на телефонах. После выступлений ведущий раскрывает выборы, а игра пересчитывает пять глобальных показателей и очки команд.

Шесть кризисных раундов, три варианта итогового исхода и экспорт результатов в CSV. Сценарии 2027 года вымышлены; это учебная модель, а не прогноз.

## Firebase

Приложение загружает общую конфигурацию из `../firebase-config.js`, аналогично игре `revolyuciya`. Комнаты новой игры используют отдельную ветку Realtime Database: `china_world_politics/КОД`.

**Внимание:** для реального подключения студентов с разных устройств правила Firebase должны разрешать необходимые действия для нового пути. Публикация кода GitHub не меняет правила Firebase и не гарантирует доступ к базе. Если Firebase недоступен, приложение автоматически предлагает локальный демонстрационный режим, который работает только в рамках браузера на одном компьютере.

**Приватность:** скрытие вариантов решения до раскрытия обеспечивается интерфейсом игры, а не защищёнными ролями Firebase. Не используйте игру для хранения конфиденциальной информации или персональных данных студентов без отдельных механизмов контроля доступа.

## Организация проекта

- `kitay/index.html` — самодостаточное игровое приложение.
- `firebase-config.js` — общий файл конфигурации в корне репозитория.
- `revolyuciya/` — другая игра, её файлы не изменяются.
