# Колесо знаний

Командная викторина по курсу «Основы российской государственности» (и по теме «Демократия»).
Ведущий крутит колесо, команды делают ставки, студенты на смартфонах видят то же самое в реальном времени.

Адрес игры: https://voran1987.github.io/parlamentiya/koleso-znaniy/

## Один раз: обновить правила базы

Используется тот же проект Firebase, что у «Парламентии» (`../firebase-config.js`) и тот же ключ ведущего.
В консоли Firebase: Realtime Database → Rules → вставьте содержимое `../database.rules.json` (добавлен узел `koleso`) → Publish.

## Как пользоваться

- Ведущий один раз открывает `https://voran1987.github.io/parlamentiya/koleso-znaniy/?key=ВАШ_КЛЮЧ` (тот же ключ, что в узле `secret`). Вверху надпись «режим ведущего».
- Студенты открывают `https://voran1987.github.io/parlamentiya/koleso-znaniy/` без ключа и видят игру без кнопок управления.
- Если ведущий видит «Не сохранено: проверьте ключ ведущего», ключ в ссылке не совпадает со значением `secret`.
- Новая игра: кнопка «Новая игра» вверху.
