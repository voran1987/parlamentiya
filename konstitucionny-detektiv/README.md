# Конституционный детектив — памятка ведущего

**Курс:** Основы российской государственности (МЭИ). **Время:** 90 минут. **Команд:** 6.

## Запуск
1. Открыть [кабинет ведущего](https://voran1987.github.io/parlamentiya/konstitucionny-detektiv/).
2. Нажать «Создать новую игру». На экране сразу появится QR-код и ссылка-приглашение.
3. Студентам открыть приглашение на телефонах, выбрать свободную команду. Код доступа вручную не вводится.
4. Один капитан с устройства управляет ответами команды. Не закрывайте вкладку ведущего, сохраняйте тот же браузер для восстановления.

## Тайминг и действия
| Этап | Мин | Действие ведущего | Действие команды |
|---|---:|---|---|
| Получение дела | 10 | Объявить задачу, распределить команды | Прочитать фабулу, выделить неизвестные факты |
| Сбор доказательств | 20 | Открыть этап | Выбрать **до трёх из четырёх** документов за жетоны |
| Предварительная версия | 15 | Открыть форму гипотез | Одно сообщение с объяснением версии (минимум 40 символов) |
| Неожиданный поворот | 5 | Открыть новый факт, предложить переоценить гипотезу | Обсудить, какие выводы меняются |
| Перекрёстная экспертиза | 15 | Открыть обмен версиями | Критически оценить версию следующей по списку команды, задать вопрос |
| Итоговое заключение | 20 | Начать финальную сдачу | Один окончательный развёрнутый ответ (не менее 100 символов) |
| Результаты | 5 | Оценить заключения, обсудить решения | Сравнить выводы с разбором |

**Сумма — 90 минут.** Этапы переключаются только ведущим и синхронизируются между телефонами.

## Шесть дел
1. **Архив:** «Закон, которого не было». Юридическая сила текста, стадии законодательного процесса, официальное опубликование.
2. **Федерализм:** «Регион против Федерации». Федеральные энергетические системы, разграничение полномочий.
3. **Права человека:** «Приказ о молчании». Свобода слова и допустимые ограничения.
4. **Исполнительная власть:** «Указ особого назначения». Президент, Правительство, иерархия нормативных актов.
5. **Местное самоуправление:** «Исчезнувшие полномочия». Конституционные основы местного самоуправления.
6. **Правосудие:** «Решение без суда». Компетенция судебных органов, пределы действия публичного заявления.

В каждом кейсе из четырёх материалов команда может открыть только три, поэтому ей нужно расставить приоритеты. Преподаватель в своём кабинете видит **все материалы, правильную модельную оценку, версии и ответы**.

## Оценивание (каждая команда — до 100 баллов)
- Правильная постановка юридической проблемы — до 15.
- Анализ компетенции — до 15.
- Использование доказательств — до 20.
- Конституционно-правовая аргументация — до 20.
- Практически осуществимое правомерное решение — до 15.
- Существенное замечание к версии другой группы — до 10.
- Рациональная работа с ограниченными запросами — до 5.

Оценка вводится в кабинете ведущего. Автоматического оценивания свободных юридических заключений нет — это сделано намеренно.

## Технические ограничения и безопасность
- Хранение сессий: отдельная таблица Supabase с включённым RLS и без прямого доступа анонимных пользователей. Серверная функция проверяет токены ведущего и капитана.
- Ссылки на вход не требуют пароля; **любой обладатель приглашения** может занять свободную команду. Не публикуйте приглашение за пределами аудитории.
- Управление ведущего восстанавливается на исходном устройстве и в исходном браузере; отдельной парольной авторизации на другом устройстве нет.
- Вымышленные фабулы не заменяют юридической консультации. Нормативная основа: [текст Конституции РФ на сайте Минюста](https://www.minjust.gov.ru/ru/documents/8011/).
