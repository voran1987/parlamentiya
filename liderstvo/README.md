# Политическое лидерство 2.0 — Республика Арея

Учебный браузерный симулятор для пяти делегаций (максимум 30 участников). Ведущий создаёт комнату и демонстрирует QR-код, участники подключаются со смартфонов.

## Открыть
https://voran1987.github.io/parlamentiya/liderstvo/

## Возможности
- 8 кризисов по исходной деловой игре: коррупция, экономика, протесты, международный конфликт, выборы, конституция, экология, финальный кризис.
- Индивидуальные голоса студентов; командная позиция определяется большинством голосов внутри каждой делегации. Первый вошедший — руководитель делегации; его привилегии ограничены сервером.
- Закрытые ответы до публикации результатов; межделегационные переговоры и взаимно подтверждённые союзы.
- Специальные политические полномочия; сохраняемый журнал решений; экспорт CSV.
- Общие показатели: доверие, экономика, политическая стабильность; очки и личная миссия.
- Последствия с задержкой на следующий раунд; несколько вариантов политического исхода.
- Ведущий управляет фазами и видит явку по комнатам, может корректировать баллы и проводить автотест 300 случайных партий.
- Сервер валидирует токены и полномочия; данные не открыты для прямой записи из браузера.

## Архитектура
- `index.html` — веб-интерфейс для GitHub Pages.
- `supabase/index.ts` — серверная Edge Function `political-leadership`.
- Supabase table `public.pl_rooms`: code, host_hash, state, version, updated_at, created_at, expires_at.
- Хранилище состояния и секретов доступа — на сервере. Токены учителя и участников хранятся только в sessionStorage конкретного браузера.

## Порядок игры
1. Ведущий нажимает «Создать новую игру».
2. Проецирует QR-код/короткий код; студенты подключаются.
3. Ведущий открывает сценарий, переговоры, закрытое голосование и итоги.
4. В финале сохраняет CSV-протокол, проводит обсуждение.

## Ограничения и рекомендации
- Первая версия: перед занятием необходимо протестировать реальные смартфоны и доступность QR-сервиса.
- Реализованы адресная и публичная переписка между делегациями, наглядный таймер фаз, ручная корректировка очков и показателей, моделирование 300 случайных партий из панели ведущего. Таймер информационный: этап не заканчивается автоматически. Не реализовано восстановление токена после закрытия вкладки или смены браузера.
- Внешний QR-изображение загружается из qrserver.com; если сервис недоступен, участник вводит код комнаты.
- Одновременные изменения защищены номером версии и повторной попыткой; при сетевой ошибке повторите действие.
- Не удалять существующие игры в Supabase; новая версия использует отдельную таблицу pl_rooms и отдельную Edge Function.
- Численные эффекты решений и роли — игровая модель, которую следует отбалансировать после пилотного занятия.

## Формальные уточнения правил
- Пороги кризиса: ниже 20.
- Силовые структуры получают кризисное вето при стабильности ниже 20.
- Вариант конституционной реформы усиливающий президента требует поддержки трёх делегаций.
- Руководитель делегации — первый вошедший игрок; только он утверждает союзы и специальные действия.
- При равенстве внутренних голосов используется первый из доступных вариантов; это упрощение первой версии.

Сохранены педагогическая структура и восемь кризисов исходных материалов; машинно-определённые эффекты и условные финалы дополнены для онлайн-версии.
