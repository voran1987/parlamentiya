# Революционная ситуация: игра на смартфонах

Тема 6 «Политическая конфликтология». Ведущий создаёт игру, команды входят по QR-коду и тайно выбирают решения у себя в телефоне, проектор показывает общее табло.

Адрес: https://voran1987.github.io/parlamentiya/revolyuciya/

## Как провести игру

1. Ведущий открывает адрес, нажимает «Создать игру» и выбирает число команд, время выступлений и кулуаров.
2. Кнопка «Открыть экран проектора» открывает табло в новом окне. Если окно не открылось, скопируйте ссылку на экран и откройте её на компьютере с проектором.
3. Команды сканируют QR-код (или вводят код из четырёх символов), выбирают роль и ждут начала.
4. В каждом раунде: событие, публичные выступления, кулуарные переговоры, тайный выбор с телефонов, открытие решений ведущим. Лучшую речь команды выбирают голосованием на телефонах, ведущий отмечает победителя.
5. Если у команды нет телефона, ведущий выбирает за неё кнопкой «выбрать за команду».

Ведущий должен оставаться в игре: его окно считает результаты раунда. Если он закрыл страницу, код игры остаётся, на главной появится «Продолжить игру».

## Правила базы данных

Игра хранит данные в узле `revolyuciya/КОД` базы Firebase того же проекта, что и остальные игры. Правила для узла добавлены в `database.rules.json` в корне репозитория. Чтобы они заработали, их нужно один раз опубликовать в консоли Firebase (Realtime Database → Rules → Publish). Узлы `board` и `koleso` в правилах не менялись.

Узел `revolyuciya` открыт для чтения и записи тому, кто знает код игры из четырёх символов. Ключ ведущего здесь не нужен, потому что решения пишут сами команды. Для учебной игры этого достаточно, но данные в узле не защищены от тех, кто знает код.

## Тестовый режим

Если Firebase недоступен, игра работает между вкладками одного браузера (для проверки на одном компьютере).
